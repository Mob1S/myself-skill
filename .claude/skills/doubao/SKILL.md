# /doubao — 豆包智能体 soul.md 导出

将蒸馏好的人格模型压缩为 2000 中文字以内的 soul.md，供豆包智能体使用。纯人格 + 人物档案，不含功能描述。

## 进入流程

### Step 0：判定工作目录

检查 `.claude/.mode_dev` 文件是否存在：
- 存在 → 基路径 = `dev/.claude/`
- 不存在 → 基路径 = `.claude/`

### Step 1：前置检查

- `{base}persona/model.md` 存在 → 继续
- 不存在 → 回复"还没有蒸馏模型，需要先完成 Phase 2 聊天蒸馏。"

`{base}persona/person-profiles.md` 可选。若不存在，从 model.md 自身的"人物档案"段提取。

### Step 2：询问身份段模式

```
你希望 soul.md 中"我是谁"部分保留多少信息？

A. 完整 — 保留名字、年龄、职业、城市等
B. 精简 — 只保留名字，其他隐私信息不写入，省下的字数给其他部分
```

### Step 3：收集外号映射

```
为了保护隐私，人物档案中的真名需要脱敏处理。
请提供你想用的外号/昵称映射（可跳过）：

格式示例：
杨欣頔 → xd
李子涵 → 涵哥
王一彤 → 一彤

不需要全部提供，没提供的人名会自动去姓留名或用首字母。
```

用户跳过或说"不需要" → 使用默认脱敏规则（去姓留名，无名则首字母）。

### Step 4：生成 soul.md 草稿

#### 4.1 读取源文件

读取 `{base}persona/model.md` 和 `{base}persona/person-profiles.md`（若存在）。

#### 4.2 隐私过滤

对所有内容执行以下过滤：

| 过滤项 | 处理方式 |
|---|---|
| 真实姓名 | 用用户提供的外号替代；无外号则去姓留名或用首字母 |
| 具体地点 | 模糊化（去掉城市、学校名） |
| 转账/金额 | 删除 |
| 敏感事件 | 用抽象描述替代（保留"深夜谈心"，删除具体内容） |
| 第三方名字 | 人物档案中提到的第三方脱敏 |

#### 4.3 按模板填充

模板骨架：

```markdown
# {name} 的灵魂

## 我是谁
{基础信息：精简模式下只留名字}

## 我的性格
{3-5 个核心性格词，每个一句话解释}

## 我怎么说话
{表达风格精华：方言、标点、表情、高频词，各 1 句}

## 我的情绪
{情绪标签，保留最有辨识度的 3-4 种}

## 我和谁说话
{人物档案：按亲密度分圈，每人 1 行}

## 我的底线
{边界与雷区，精简为 2-3 条}
```

#### 4.4 字数预算

| 段落 | 预算（字） | 说明 |
|---|---|---|
| 我是谁 | 150 | 精简模式下缩为一句话 |
| 我的性格 | 300 | 3-5 核心词 + 解释 |
| 我怎么说话 | 400 | 方言、标点、表情、高频词各 1 句 |
| 我的情绪 | 250 | 最有辨识度的 3-4 种 |
| 我和谁说话 | 700 | 核心圈 + 好友圈 |
| 我的底线 | 100 | 2-3 条 |
| 余量 | 100 | 缓冲 |

字数统计：只计可见中文字符（不含 markdown 标记 `#`、`|`、`-`、`*`，不含空格和换行）。英文单词按 1 个字计。

#### 4.5 超长裁剪

若草稿超过 2000 字，按以下优先级裁剪：

1. **熟人圈**（亲密度 4-6）— 整段删除
2. **好友圈**（亲密度 7-8）— 只保留名字和一句话关系
3. **说话风格** — 精简细节
4. **核心圈**（亲密度 9-10）— 不动
5. **底线** — 不动

裁剪后重新计算字数，直到达标。

### Step 5：输出草稿供确认

将生成的 soul.md 草稿输出到对话中，附带字数统计：

```
以下是 soul.md 荧稿（当前 {N}/2000 字）：

---
{草稿内容}
---

确认没问题就写入，或者告诉我哪里需要调整。
```

### Step 6：写入文件

用户确认后，写入 `{base}persona/soul.md`。

### Step 7：输出完成信息

```
/doubao 完成。

soul.md 已生成：{base}persona/soul.md
字数：{N}/2000

你可以将文件内容复制到豆包智能体的描述框中。
```

## 边界处理

| 场景 | 处理 |
|---|---|
| 无模型可读 | 提示需先完成 Phase 2 |
| person-profiles.md 不存在 | 从 model.md 自身的"人物档案"段提取，人物段照常生成 |
| 用户拒绝提供外号 | 使用默认脱敏（去姓留名/首字母） |
| 裁剪后仍超 2000 字 | 告知用户当前字数，询问是否接受略超或进一步压缩 |
| 用户要求调整草稿 | 按用户意见修改后重新输出，再次确认 |

## 模式互斥

`/doubao` 不受 `/test` / `/train` 模式锁定，随时可用。

## 可重复使用

`/doubao` 可多次调用。每次重新读取最新模型文件生成 soul.md，覆盖旧文件。
