
# myself-skill — 人格蒸馏向导

在尝试了 [ex-skill](https://github.com/therealXiaomanChu/ex-skill) 后，我必须说，它让我回到了那段时光，一时间甚至有些恍惚。你也可以去试一试。但我相信你很快会意识到一个问题——它蒸馏的只是那段时光的 ta，而万事万物都在变化，我猜你也变了许多。蒸馏过程中你会把时间往回拨，看到那段时光你说过的话，你开始后悔，觉得那时候自己怎么那么傻，这种懊悔真让人沮丧不是吗。我猜当你对 ta 说"我们和好吧"，模型不会拒绝，它会给你答复。但你知道，这一切没有发生，你沉溺在这里，不知道是该喜还是该悲。

让我们把这招用到自己身上，蒸馏出你自己的模型吧。起码你会知道你会做出怎样的回答，不是吗。来试试。

将你的聊天记录和自述蒸馏为一个可调用的数字分身 Skill。通过 5 阶段引导式流程，创建一个能模仿你说话方式、性格特征和互动模式的 AI 人格模型。

## 快速开始

1. 在 Claude Code 中加载本 Skill
2. 说"帮我蒸馏我的说话风格"或"我想做一个我的数字分身"
3. 跟随向导完成 5 个阶段

## 工作流程

| 阶段 | 触发方式 | 说明 |
|---|---|---|
| **Phase 1：身份锚定** | 自动 | 逐题问答，收集你的基础身份、性格核心、角色定位、表达风格、边界雷区 |
| **Phase 2：聊天蒸馏** | 自动 | 上传聊天记录，从 6 个维度分析语言指纹，生成 V1 模型 |
| **Phase 3：测试模式** | `/test` | 他人扮演者测试模型准确度，标注"像/不像"来校准 |
| **Phase 4：训练模式** | `/train` | 你做真实的自己，模型扮演角色从对话中学习 |
| **Phase 5：生成 Skill** | `/skill` | 基于最终模型生成独立的可调用人格 Skill |

## 核心指令

| 指令 | 说明 |
|---|---|
| `/{你的名字}` | 与你的数字分身对话 |
| `/bye` | 退出人格对话模式 |
| `/test` | 进入测试模式 |
| `/train` | 进入训练模式 |
| `/next` | 在 test/train 中切换角色 |
| `/fine` | 保存调整并退出测试模式 |
| `/end` | 总结收获并退出训练模式 |
| `/status` | 查看当前模型状态 |
| `/skill` | 生成最终 Skill 文件 |
| `/enrich` | 用额外文件加权丰富人格模型 |
| `/deep` | 深度二次阅读聊天记录，挖掘遗漏细节 |
| `/wechat-export` | 微信聊天记录导出引导，推荐工具并协助安装 |
| `/protect` | 隐私保护向导 |
| `/doubao` | 导出豆包智能体 soul.md（2000字人格压缩） |

蒸馏完成后生成以下文件：

```

│   ├── model.md                   # 人格模型（含版本号）
│   ├── rules.md                   # 调用规则（可跨对话唤醒）
```

## 设计原则

- **一次一问**：Phase 1 的 5 个问题逐个提出，不给用户压迫感
- **用户节奏**：Phase 1-2 主动引导，Phase 3-5 由用户通过指令触发
- **文件即契约**：所有中间产物持久化保存，test/train/skill 指令依赖这些文件
- **版本管理**：Minor +0.1 / Major +1，每次变更记录 CHANGELOG

## 语言指纹分析维度

聊天蒸馏阶段会从以下 6 个维度分析你的说话方式：

1. **高频词与口头禅** — Top 20 有个人特色的高频词汇
2. **句式特征** — 句长、分行习惯、标点、句尾、倒装模式
3. **Emoji/表情包使用模式** — Top 10 表情及场景、使用频率
4. **情绪表达方式** — 7 种情绪的典型表达及原文示例
5. **对话角色特征** — 主动/被动比例、话题发起方式
6. **特殊语言习惯** — 独有词汇、圈子黑话、网络梗使用

## 设计思路

**`/{你的名字}` 与 `/bye`** — 模型通过这种方式被调用，非常有意思不是吗。开始项目时我想之后把我的模型发给朋友，让他们可以与蒸馏后的我对话，因此我还特意添加了人物档案，让模型可以记住聊天记录里的人。而 `/bye` 让你像朋友一样与模型道别，也许你的朋友以后用得到。

**`/test` `/train` `/fine` `/end`** — 这四个模块让你可以对模型做出调整。通过 `/test` 测试模型是否符合预期并校准，当你觉得差不多了，你会很开心，所以一句 `/fine`，让我们表达出这种欣喜。`/train` 让模型更加像你，当你想结束了，`/end` 一下吧，适当的休息也是很重要的。

**`/protect`** — 如果你像我一样想把模型发给朋友，但又害怕隐私文件被看到（蒸馏后的聊天记录也是非常隐私的文件），那就 `/protect` 一下吧。

**`/enrich`** — 读取其他文件，比如你写的文章、你对某些事物的看法、你内心深处的想法、你的价值观等等。`/enrich` 一下，让模型更加丰富。

**`/wechat-export`** — 不会导出微信聊天记录？让我们来帮你。

**`/deep`** — 初次蒸馏可能由于读取太多文件而比较粗略，也许模型过拟合把不属于你的说话习惯保存了下来，也许一些你很珍重的人的聊天记录没有被好好阅读。无论如何，`/deep` 一下，让模型和人物档案更加生动。

**`/dev`** — 这个模式本来应该仅仅为我开发，阴差阳错地公布了出来。我相信你下载了我的源码。事已至此，如果你还有一些改善模型的想法，`/dev` 一个环境，在这里调试你的模型，`/exit` 后总结你的工作对模型做出更改。你甚至可以创造一个新的模块来帮助改善你的模型。如果你有什么好办法，Issue 我或者给我发邮件。如果你的思路戳中了我，我会根据你的思路更新 Skill。

## 隐私与数据安全

- **数据本地化**：本项目所有数据（聊天记录、人格模型、人物档案）均存储在用户本地设备上，不会上传到任何云端服务
- **用户责任**：聊天记录涉及对话双方的个人信息。使用前请确保你已获得聊天记录中其他参与者的知情同意，或确保这些数据仅用于个人用途
- **隐私保护**：`/protect` 指令可帮助你生成 `.gitignore`，防止隐私文件被 git 追踪或公开推送
- **第三方脱敏**：`/doubao` 导出时自动对人物档案中的真名、地点等隐私信息进行脱敏处理

## 使用限制

请勿将本项目用于以下用途：

- **冒充他人**：不得使用蒸馏模型冒充真实身份进行欺诈、误导或损害他人利益
- **未经同意的建模**：不得在未告知的情况下对他人进行人格建模
- **违法用途**：不得用于任何违反当地法律法规的活动
- **商业欺骗**：不得将数字分身用于商业场景中的身份冒充
