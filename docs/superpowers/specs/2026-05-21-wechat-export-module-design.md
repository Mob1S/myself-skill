# /wechat-export 微信聊天记录导出引导模块设计

## 概述

`/wechat-export` 是一个独立的引导式指令模块，帮助用户导出微信聊天记录用于蒸馏分析。当用户不知道如何导出微信聊天记录时，系统推荐工具链、协助安装、逐步引导使用，并在导出完成后无缝衔接到蒸馏流程。

## 触发方式

- **独立指令**：用户输入 `/wechat-export`，或自然语言如"怎么导出微信聊天记录""微信聊天记录怎么导出"
- **Phase 2 联动**：Phase 2 Step 1 末尾新增一行："不知道如何导出微信聊天记录？输入 `/wechat-export` 我帮你搞定。"

## 指令文件

`.claude/skills/wechat-export/SKILL.md`

遵循现有 Skill 模块的轻量模式，所有逻辑内联。

## 整体流程

```
用户不知道怎么导出
      ↓
推荐工具链：WeFlow（主力）→ 密钥获取失败 → WechatDump202601（兜底）
      ↓
用户说"帮我装"
      ↓
检测平台（Windows / macOS / Linux）
      ↓
下载对应安装包到用户下载目录
      ↓
询问用户"是否授权自动安装？"
   ├─ 是 → 执行静默安装
   └─ 否 → 告知文件位置，等用户手动安装后说"好了"
      ↓
逐步引导使用：
  1. 打开 WeFlow → 等用户确认
  2. 自动获取密钥 → 等结果
     ├─ 成功 → 跳至步骤 3
     └─ 失败 → 推荐 WechatDump202601 手动提取密钥 → 同流程安装引导 → 填入 WeFlow
  3. 选择联系人/群聊 → 导出为 TXT → 等用户确认
      ↓
询问"要不要直接载入蒸馏流程？"
   ├─ 是 → 读取文件，进入 Phase 2 Step 2 分析
   └─ 否 → 告知文件路径，用户随时可发来蒸馏
```

## 工具链

| 工具 | 用途 | 状态 |
|---|---|---|
| [WeFlow](https://github.com/hicccc77/WeFlow) | 微信聊天记录查看、分析、导出（主力） | 主力推荐，协助下载安装 |
| [WechatDump202601](https://github.com/Zst0NE/WechatDump202601) | 手动提取微信数据库密钥（兜底） | 仅供参考，告知仓库地址，不主动下载 |

## 进入流程

### Step 0：判定工作目录

检查 `.claude/.mode_dev` 文件：
- 存在 → 基路径 = `dev/.claude/`
- 不存在 → 基路径 = `.claude/`

### Step 1：推荐工具

首次使用时输出工具链推荐，含安全说明：

> "要导出微信聊天记录，推荐使用 WeFlow（https://github.com/hicccc77/WeFlow）——开源的微信聊天记录分析和导出工具，完全本地运行，支持导出为 TXT、HTML、JSON 等格式。
>
> WeFlow 是开源工具（GitHub 7k+ stars），完全本地运行，不会上传你的聊天记录。但如果你有顾虑，也可以手动复制粘贴——在微信中选中对话，复制后粘贴到 txt 文件里发给我。如果你使用的模型支持多模态，直接截图粘贴给我也行。
>
> 需要我帮你下载安装吗？"

### Step 2：安装引导

**2.1 检测平台**

自动检测当前操作系统。

**2.2 下载**

从 GitHub Releases 下载最新版本到用户下载目录。下载前告知下载链接，用户确认后执行。

**2.3 安装**

询问用户是否授权自动安装：

- 授权 → 执行静默安装：
  - Windows: `start /wait xxx.exe /S`
  - macOS: `hdiutil attach xxx.dmg && cp -R /Volumes/WeFlow/WeFlow.app /Applications/`
  - Linux: `chmod +x xxx.AppImage`
- 不授权 → 告知文件位置，等用户手动安装后说"好了"
- 安装失败 → 告知错误信息，回退到手动安装模式

### Step 3：逐步使用引导

每一步等用户确认"好了"再进入下一步。

**3.1 打开 WeFlow**

> "打开 WeFlow，它会自动检测你电脑上的微信。确认微信已登录，然后告诉我'好了'。"

WeFlow 提示"未检测到微信" → 确认微信版本 ≥ 4.0 → 确认微信已登录 → 重试。

**3.2 获取密钥**

WeFlow 自动尝试获取数据库密钥。等用户反馈结果：

- **成功**：> "密钥获取成功。接下来选择你要导出的联系人或群聊，然后告诉我'好了'。"
- **失败**：> "自动获取密钥失败了。可以试试 WechatDump202601（https://github.com/Zst0NE/WechatDump202601），这是一个专门的密钥提取工具。下载运行后把密钥填入 WeFlow 的'手动输入密钥'即可。需要我帮你下载这个工具吗？"

用户搞不定密钥 → 不阻塞，建议回退到手动复制粘贴或截图方案。

**3.3 导出聊天记录**

> "在 WeFlow 中选择导出格式为 TXT，选择导出范围（建议选'全部'），点击导出。完成后把文件路径发给我。"

### Step 4：衔接到蒸馏流程

导出完成后询问：

> "聊天记录已导出成功。要不要我直接加载这个文件开始蒸馏分析？"

- 用户同意 → 读取文件内容，进入 Phase 2 Step 2 的 6 维度分析流程。如果 model.md 已存在，按增量更新处理，版本号 +0.1
- 用户拒绝 → "好的，文件在 `{path}`。你随时可以把文件发给我或输入 `/enrich` 来蒸馏。"

## 边界处理

| 场景 | 处理 |
|---|---|
| 不在 Windows/macOS/Linux 上 | 告知当前不支持该平台，建议手动复制粘贴或截图 |
| 下载失败（网络问题） | 告知下载链接，建议用户手动下载 |
| 安装失败 | 告知错误信息，回退到手动安装模式 |
| 密钥获取两次都失败 | 不阻塞，建议回退到手动复制粘贴或截图方案 |
| WechatDump202601 信息不足 | 仅告知仓库地址和用途，由用户自行决定是否使用 |
| 用户在 test/train 模式中调用 | 不受锁定，正常执行 |
| 模型不支持多模态 | 截图方案会自动降级为复制粘贴方案 |
