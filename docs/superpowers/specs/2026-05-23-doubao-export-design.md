# /doubao — 豆包智能体 soul.md 导出模块设计

> 日期：2026-05-23

## 背景

用户希望将蒸馏好的人格模型导出为豆包智能体的描述文件（soul.md），供豆包平台的智能体使用。豆包智能体描述上限为 **2000 中文字**。

## 目标

- 创建 `/doubao` 指令，读取 `model.md` + `person-profiles.md`
- 按模板骨架压缩为 2000 字以内的 `soul.md`
- 纯人格 + 人物档案，不包含功能描述
- 自动过滤隐私信息
- 输出草稿供用户确认后再写入

## 模板骨架

```markdown
# {name} 的灵魂

## 我是谁
{基础信息}

## 我的性格
{核心性格}

## 我怎么说话
{表达风格}

## 我的情绪
{情绪标签}

## 我和谁说话
{人物档案}

## 我的底线
{边界与雷区}
```

### 字数预算

| 段落 | 预算（字） | 说明 |
|---|---|---|
| 我是谁 | 150 | 可选精简模式，只留名字 |
| 我的性格 | 300 | 3-5 个核心词 + 一句话解释 |
| 我怎么说话 | 400 | 方言、标点、表情、高频词各 1 句 |
| 我的情绪 | 250 | 保留最有辨识度的 3-4 种 |
| 我和谁说话 | 700 | 核心圈 + 好友圈，按优先级裁剪 |
| 我的底线 | 100 | 精简为 2-3 条 |
| 余量 | 100 | 缓冲 |
| **合计** | **2000** | |

### 身份段精简模式

用户可选择只保留名字，不暴露年龄、职业、城市等隐私信息。省下的字数分配给其他段落（优先给人物档案）。

## 隐私过滤规则

| 过滤项 | 处理方式 |
|---|---|
| 真实姓名 | 用用户提供的外号/昵称替代；无外号则去姓留名或用首字母 |
| 具体地点 | 模糊化（去掉城市、学校名等） |
| 转账/金额 | 删除 |
| 敏感事件 | 用抽象描述替代（保留"深夜谈心"，删除具体内容） |
| 第三方名字 | 人物档案中提到的第三方脱敏 |

## 裁剪优先级

当字数超出 2000 时，按以下顺序裁剪：

1. **熟人圈**（亲密度 4-6）— 整段删除
2. **好友圈**（亲密度 7-8）— 只保留名字和一句话关系描述
3. **说话风格** — 精简细节
4. **核心圈**（亲密度 9-10）— 不动
5. **底线** — 不动

人物从不熟的开始删，直到字数达标。

## 输出位置

`.claude/persona/soul.md`

## 指令流程

1. 读取 `.claude/persona/model.md` 和 `.claude/persona/person-profiles.md`
2. 询问用户身份段模式：完整 / 精简（只留名字）
3. 询问用户是否提供外号映射（真名→外号）
4. 按模板骨架 + 字数预算 + 隐私过滤规则生成 soul.md 草稿
5. 输出草稿到对话中，附带字数统计（如"当前 1823/2000 字"）
6. 等用户确认或提出调整
7. 用户确认后写入 `.claude/persona/soul.md`

## 字数统计

统计 soul.md 正文内容的可见中文字符数（不含 markdown 标记符号如 `#`、`|`、`-`、`*`，不含空格和换行）。英文单词按 1 个字计。

## 前置条件

- `.claude/persona/model.md` 必须存在（Phase 2 聊天蒸馏完成）
- `.claude/persona/person-profiles.md` 可选（若不存在，从 model.md 自身的"人物档案"段提取）

## 文件结构

新增一个 Skill 文件：

```
.claude/skills/doubao/SKILL.md
```

## 不做的事

- 不包含功能描述（能做什么、怎么用）
- 不包含对话启动协议
- 不包含深层行为结构
- 不包含称呼体系详细映射
- 不自动生成外号（由用户提供）
